# 装配与检查

## 装配

1. **外壳。** 有两个开口的盒子：进气口和出气口。根据你的滤芯打印外壳或改造现成盒子。
2. **沿气流方向的层顺序**：进口 → HEPA → 活性炭 → 风机（吹出方式） → 出口。接缝不留间隙：空气会走阻力最小的路，如果有缝隙就会绕过过滤层。
3. **传感器** —— 在进气流上，过滤器前：它应该闻脏房间空气，不是净化后的。
4. **电子产品** —— 单独室或墙边，远离气流。板子——用支架，别乱堆。
5. 固定电线：风机振动会随时间松动没固定的东西。

## 全面检查表

按顺序检查——每一步都依赖前面的。

| # | 检查 | 怎么做 |
|---|---|---|
| 1 | 电源 | 风机线上12V，buck后5V，传感器上3.3V |
| 2 | 传感器活着 | Serial日志中：清洁空气~100，呼吸时升高 |
| 3 | 设备Online | 在应用中绑定后门户上的状态 |
| 4 | 遥测 | 设备流中有`vocIndex`和`fanStatus` |
| 5 | 卡片 | VOC和风机单元格、Mode列表、Threshold字段 |
| 6 | 门户命令 | Mode → `on`：风机打开，卡片显示"打开" |
| 7 | 自动 | Mode → `auto`，吹气：在阈值打开，阈值以下关闭 |
| 8 | 重启 | 模式和阈值保存，卡片自动激活 |
