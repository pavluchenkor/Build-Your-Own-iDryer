# 組立と確認

## 組立

1. **ケース。** 2つの開口部付きボックス: 空気の入口と出口。フィルターカートリッジに合わせて3Dプリントするか、既製品のボックスを加工します。
2. **気流に沿った層の順序:** 入口 → HEPA → 活性炭 → ファン（排気側） → 出口。隙間をなくすこと: 空気は楽な方へ流れ、隙間があればフィルターを迂回します。
3. **センサー** — 入口側、フィルターの手前に配置: 部屋の汚れた空気を検知するためで、浄化後の空気を検知してはいけません。
4. **電子機器** — 独立したコンパートメントか壁面に、粉塵の流れから離して配置。基板はスタンドオフに固定し、置きっぱなしにしないでください。
5. ケーブルを固定すること: ファンの振動は時間とともに固定されていないものをすべて緩めます。

## 包括的チェックリスト

順序でチェック — 各ポイントは前のものに依存。

| # | チェック | 方法 |
|---|---|---|
| 1 | 電源 | 12 Vをファンラインに、バック後5 V、センサーに3.3 V |
| 2 | センサー動作 | シリアルログでクリーンな空気時に~100、息を吹きかけると上昇 |
| 3 | デバイス Online | アプリでのペアリング後のポータルの状態 |
| 4 | テレメトリ | デバイスストリームに`vocIndex`と`fanStatus` |
| 5 | カード | VOCと ファンセル、Modeリスト、Thresholdフィールド |
| 6 | ポータルコマンド | Mode → `on`: ファン起動、カード「オン」表示 |
| 7 | オートメーション | Mode → `auto`、息を吹きかける: 閾値で起動、下で停止 |
| 8 | リセット | モードと閾値保存、カード自ら復活 |

## この先

フィルターは完成です。あとはお好みで:

- **エンティティを追加**: 「5分強制換気」ボタン（`card().button(...)`）、第2センサー、フィルター稼働時間カウンターと交換リマインダー;
- **レイアウトを整える**: `layoutRow`はすでに使いました;
- **独自デバイスを作る**: このセクション全体がテンプレートです。センサー、アクチュエーター、ロジックを置き換えれば — 同じスキームで加湿器、排気コントローラー、何でも組めます。マニフェストがインターフェースを自動で作ります。

何かが動かない場合 — [よくあるエラー](../08-common-mistakes/01-overview.md)。
