# 智慧空氣濾清器：概念

這是「自己動手組裝」章節的第二個完整範例。在[第一個範例](../09-build-a-device/01-concept.md)中，你用生態系統的「詞彙磚塊」組裝了一個加熱機櫃：溫度、濕度、加熱器。在這裡，我們更進一步——組裝一個**生態系統中根本沒有的裝置**：配有揮發性有機化合物（VOC）感測器的空氣濾清器。

## 核心理念：這是概念，而非單一裝置的配方

請仔細閱讀本段——它比整章節都重要。

濾清器只是例子。所展示的方法對**任何你想到的裝置都有效**：加濕器、吹風站、排氣控制器、膠捲儲存監測站，什麼都可以。你在韌體中宣告裝置有哪些感測器和控制——每個只需一兩行程式碼——然後裝置**自動出現在入口網站和行動應用程式**上，配有現成卡片：即時讀數、按鈕、輸入欄位。入口網站那邊沒有一行程式碼要寫，也不需要與 iDryer 方面達成協議，也沒有 pull request。

這歸功於**動態卡片**機制（entity manifest）：裝置發佈機器可讀的描述「要顯示什麼和用什麼控制」，入口網站和應用程式根據這份描述組建介面。代碼是什麼樣子——見[卡片章節](06-card.md)。

!!! note "實踐意義"
    想到了一個裝置 → 在 ESP32 上組裝 → 在韌體中描述感測器和按鈕 → 在應用程式中綁定到帳戶。完成：裝置在入口網站和應用程式上有介面。從想法到「用智慧手機控制」的距離——一個晚上。

## 我們具體要組裝什麼

**3D 列印區域的空氣濾清器**：配有風扇、HEPA 濾清器和活性碳層的盒子，它：

- 用 VOC 感測器（SGP40）測量空氣品質；
- 當空氣髒污時自動打開風扇，當空氣清淨後關閉；
- 在入口網站上顯示 VOC 指標和風扇狀態；
- 允許從入口網站選擇模式（`auto` / `on` / `off`）並調整啟動閾值。

ABS 和 ASA 在列印時會散發苯乙烯氣味，樹脂會散發自己的氣味。列印機旁的濾清器——不是奢侈品，而是衛生需求。

## 為什麼這是理想的首個專案

如果第 09 章的機櫃看起來複雜——從濾清器開始：

- **沒有加熱器**——意味著沒有強電部分、熱熔斷器和相關風險；
- 最少的元件：主板、感測器、風扇、電晶體；
- 預算約 `$15` 不包括機殼；
- 即使程式碼有任何錯誤，最壞的情況是風扇不會打開。

## 任務邊界

誠實地說明這個濾清器**不是**什麼：

- 它不是排氣扇：空氣在濾清器中循環過濾，而不是排到室外；
- 它不是醫療裝置：SGP40 顯示空氣品質的相對**指標**，不是特定氣體的 ppm 濃度；
- 濾清器不能取代通風。

!!! note "VOC 還是 CO2？"
    對於列印蒸氣，正確的感測器是 VOC：它對有機化合物（苯乙烯、溶劑）敏感。CO2 感測器（例如 NDIR 型 MH-Z19）測量二氧化碳——這是「悶」的指標，而非列印污染。如果你既想要 VOC 又想要 CO2，ENS160 同時提供 VOC 指標和 eCO2 估計；本章節的方法不變——只是在卡片清單中多一行。
