# 配線図

シンプルな配線: I2Cセンサー、ファンがキーを通じて、共通12 V電源。

```text
12 V電源 ──┬────────────────────────► ファン（+）
          │                          ファン（−） ◄── MOSFETドレイン
          │                                             MOSFETソース ─► GND
          │                                             MOSFETゲート ◄─ GPIO4 ESP32
          │
          └─► バック 12→5 V ─► ESP32-C3 (5V)

SGP40:  VCC ─► 3V3 ESP32    SDA ─► GPIO8    SCL ─► GPIO9    GND ─► GND
```

## ピン

| シグナル | ESP32-C3 Super Miniピン |
|---|---|
| I2C SDA（SGP40） | GPIO8 |
| I2C SCL（SGP40） | GPIO9 |
| MOSFETゲート（ファン） | GPIO4 |

ピンは別のものを選択できます — その場合、コード内の番号を変更してください（[第5章](05-sensor-and-telemetry.md)）。

## 接続ルール

1. **共通グラウンド。** 電源のGND、ESP32、MOSFETモジュール、センサーはすべて接続される必要があります。DIYプロジェクトの半分が「動作しない」のは、忘れられた共通グラウンドが原因です。
2. **センサーは3.3 Vのみ。** SGP40は5 Vの電源に対応していません。
3. **ファンは必ずスイッチ経由で。** GPIOが出力できるのは数mAです。ファンは数百mAを消費します。直接接続するとピンが焼けます。MOSFETスイッチの動作原理 — [トランジスタとMOSFET](../01-electronics-basics/02-mosfet-module.md)。
4. **外付け保護ダイオード**は、PC用ファンには通常不要です: ファン内部にスイッチング回路があり、外部からは純粋なインダクタンスではなく電子負荷として見えます。ただし、スイッチによる電源ラインの断続時（特にPWM使用時）は、ファンと並列に配置したフライバックダイオードがスイッチをインダクティブスパイクから保護するために有効です — スイッチモジュールに最初から内蔵されていれば、それで十分です。

!!! warning "電源投入前に極性を確認してください"
    12 Vラインの+と−を逆に繋ぐと、バックモジュールとボードが壊れます。これはよくあるミスです。最初の電源投入前にマルチメーターで確認してください。

## ファームウェアなしでの確認

組立後、メインコードを書き込む前に:

1. 12 Vを供給 — ケーブルを繋いだときにESP32がUSBデバイスとして認識される、または電源LEDが点灯することを確認。
2. MOSFETゲートを1 kΩ抵抗を通じて3.3 Vに短絡 — ファンが起動するはずです。
3. I2Cセンサーは[第5章](05-sensor-and-telemetry.md)でファームウェアから確認します。
