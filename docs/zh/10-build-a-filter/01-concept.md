# 智能空气过滤器：概念

这是"自己动手搭建"部分的第二个贯通示例。在[第一个示例](../09-build-a-device/01-concept.md)中，你用生态系统中的"字典"积木搭建了一个加热柜：温度、湿度、加热器。这里我们更进一步——搭建一个**在iDryer生态系统中根本不存在的设备**：配备挥发性有机物（VOC）传感器的空气过滤器。

## 主要理念：这是概念，不是某个特定设备的配方

请仔细阅读这段话——它比全章其他内容都重要。

这里的过滤器只是一个例子。展示的方法适用于**你能想到的任何设备**：加湿器、吹气站、排风控制器、耗材库存监视器，任何东西。你在固件中声明设备有哪些传感器和控制器——每个只需一两行代码——设备就会**自动出现在门户和移动应用上**，配备现成的卡片：实时数据、按钮、输入框。门户端不需要一行代码，不需要与iDryer方协商，不需要pull-request。

这多亏了**动态卡片**（实体清单）机制：设备发布机器可读的描述"要显示和控制什么"，门户和应用根据这份描述构建界面。代码中的样子——见[卡片章节](06-card.md)。

!!! note "实践中意味着什么"
    想到设备 → 用ESP32搭建 → 在固件中描述传感器和按钮 → 在应用中绑定到账户。完成：设备在门户和应用上有了界面。从想法到"用手机控制"的距离——一个晚上。

## 我们具体搭建什么

**3D打印区域的空气过滤器**：一个装有风机、HEPA过滤器和活性炭层的盒子，具有以下功能：

- 用VOC传感器（SGP40）测量空气质量；
- 空气污浊时自动打开风机，清洁后自动关闭；
- 在门户上显示VOC指数和风机状态；
- 允许从门户选择模式（`auto` / `on` / `off`）并调整启动阈值。

ABS和ASA打印时会散发苯乙烯味，树脂有自己的气味。打印机旁的过滤器不是奢侈品，而是卫生必需品。

## 为什么这是最理想的第一个项目

如果第09章的加热柜显得太复杂——先试试过滤器：

- **没有加热器** —— 意味着没有强电部分、热熔断器和相关风险；
- 最少的组件：控制板、传感器、风机、晶体管；
- 预算约`$15`（不含外壳）；
- 即使代码有错，最坏的结果也只是风机不启动。

## 任务的边界

坦诚地说，这个过滤器**不是**：

- 不是排风扇：空气通过过滤器循环流动，不是排到室外；
- 不是医疗设备：SGP40显示相对的空气质量**指数**，而不是特定气体的ppm浓度；
- 过滤器不能替代通风。

!!! note "VOC还是CO2？"
    对于打印污染，正确的传感器是VOC：它反应有机物（苯乙烯、溶剂）。CO2传感器（例如NDIR型MH-Z19）测量二氧化碳——这是空气闷的指标，不是打印污染的指标。如果想要两者，ENS160既提供VOC指数又提供eCO2估计；这一章的方法不变——只是在卡片清单中多加一行。
