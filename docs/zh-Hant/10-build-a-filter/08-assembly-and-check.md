# 組裝與檢查

## 組裝

1. **機殼。** 有兩個開口的盒子：進氣口和出氣口。根據你的濾芯列印外殼，或改造現成的盒子。
2. **沿氣流方向的層順序：** 進口 → HEPA → 活性碳 → 風扇（吹出方式） → 出口。接縫不留縫隙：空氣會走阻力最小的路，如果有縫隙就會繞過過濾層。
3. **感測器**——裝在進氣流上、濾清器前方：它應該偵測房間裡的髒空氣，而非過濾後的空氣。
4. **電子設備**——裝在獨立隔間或側牆上，遠離氣流。主板用銅柱鎖固，不要隨意堆放。
5. 固定好導線：風扇振動會隨著時間鬆動所有未固定的部件。

## 全面檢查清單

按順序檢查——每個步驟都依賴前面的。

| # | 檢查 | 怎樣做 |
|---|---|---|
| 1 | 電源供應 | 12 V 在風扇線上、5 V 在降壓後、3.3 V 在感測器 |
| 2 | 感測器活著 | 序列日誌中乾淨空氣指標 ~100，吹出時增加 |
| 3 | 裝置線上 | 在應用程式中綁定後入口網站上的狀態 |
| 4 | 遙測 | `vocIndex` 和 `fanStatus` 在裝置流 |
| 5 | 卡片 | VOC 和風扇儲存格、模式清單、閾值欄位 |
| 6 | 來自入口網站的命令 | 模式 → `on`：風扇啟動，卡片顯示「開」 |
| 7 | 自動化 | 模式 → `auto`、向感測器吹氣：在閾值啟動、以下關閉 |
| 8 | 重新啟動 | 模式和閾值保存，卡片自己甦醒 |

## 後續延伸

濾清器完成。接下來——隨你發揮：

- **更多實體**：「強制運行 5 分鐘」按鈕（`card().button(...)`）、第二個感測器、濾材累計運行時間計數器（附更換提醒）；
- **精美佈局**：工廠 `layoutRow` 你已經用過；
- **自己的裝置**：整章就是範本。替換感測器、執行器和邏輯——同樣的做法可以組裝加濕器、排氣機、任何東西的控制器。Card manifest 自動生成介面。

有任何問題——[常見錯誤](../08-common-mistakes/01-overview.md)。
