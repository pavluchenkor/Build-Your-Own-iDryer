## 过滤部分

| 组件 | 例子 | 用途 |
|---|---|---|
| HEPA过滤器 | 来自汽车/家用净化器的圆形滤芯 | 捕捉颗粒 |
| 活性炭 | 颗粒盒或活性炭垫 | 吸收VOC和气味 |
| 外壳 | 打印（根据你的过滤器设计STL）或任何合适的盒子 | 固定所有部件 |

!!! note "层的顺序"
    空气流向：进口 → HEPA → 活性炭 → 风机 → 出口。风机装在过滤器之后"吹出"：这样外壳缝隙就不会绕过过滤器吸进脏空气。原则上这并不太重要——起作用的是单位时间内空气体积的循环次数：风机风量（CFM）越高，这段时间越短。

## 为什么选SGP40

- I2C，3.3V电源 —— 用两条信号线连接到ESP32；
- 输出**VOC指数** 0..500（100 = "普通空气"，数值越高越脏），不需要校准；
- 有现成的Adafruit库。

替代品：

- **ENS160** —— VOC指数 + eCO2估计，也是I2C。好的"二合一"方案；
- **MH-Z19B/C** —— 真正的NDIR CO2传感器（ppm），UART，~$20。对过滤器来说大材小用。
