# Changelog

Этот файл ведётся на русском языке и фиксирует заметные изменения в разделе Build Your Own iDryer — учебнике и сквозных примерах устройств.

## Типы изменений

- **Добавлено** — для новых функций.
- **Изменено** — для изменений в существующей функциональности.
- **Устарело** — для функций, которые скоро будут удалены.
- **Удалено** — для удалённых на данный момент функций.
- **Исправлено** — для любых исправлений багов.
- **Безопасность** — на случай уязвимостей.

## [3.0.0]

Первый выпуск.

### Добавлено

- **Сквозной пример: шкаф хранения филамента.** От концепции и комплектации до схемы, прошивки, сборки и проверки. Устройство работает и подключено к порталу.
- **Сквозной пример: умный фильтр воздуха.** Показывает главное: устройство, которого в экосистеме нет, получает карточку в портале без единой строчки кода на его стороне.
- **Учебник по электронике для сборки своими руками.** Питание и нагрузка, контроллеры, компоненты, теплофизика, инструменты, практика подключения, 3D-печать, типовые ошибки. Читается по порядку или как справочник.
